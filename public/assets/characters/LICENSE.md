# Character asset attribution

`cesium-man.glb` is **Cesium Man** from the Khronos Group glTF Sample
Assets repository.

- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/
- Original model credit: Cesium / Analytical Graphics, Inc.

The model is loaded with Three.js `GLTFLoader`, cloned with
`SkeletonUtils.clone`, and animated with `AnimationMixer`. Per-instance
material tinting and scene placement are project modifications.
